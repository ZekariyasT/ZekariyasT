# About Me

I'm **Zekariyas Tesfaye Desta**, a **Backend Software Engineer** and Master’s student in Computer Science at the University of Salzburg, Austria. I specialize in backend development with JavaScript, TypeScript, Node.js, Express, MongoDB, and SQL. I have hands-on experience building scalable REST APIs, designing complex database systems, and implementing backend architecture through real-world production platforms, including a digital freelance marketplace and an essential goods distribution platform.

### 💼 Experience & Background
- **Software Engineer (Hybrid)** at *IBEX Technologies And Promotion PLC* (Feb 2023 – Jun 2025):
  - Built backend features for a Bole Sub-City goods-distribution platform to track essential goods (cooking oil, sugar).
  - Developed coordination and tracking features for cooperatives, government offices, and retailers.
  - Contributed 15+ REST API endpoints using Node.js & Express, integrated PostgreSQL & MongoDB, and delivered 10+ backend performance improvements.
- **Software Engineer Intern** at *Dan Energy* (Mar 2022 – Oct 2022):
  - Delivered 10+ backend features using Node.js, Express, and SQL based on real project requirements.
  - Built and maintained REST APIs and database functionality across 5+ application modules, boosting performance by 20%.
- **Education:**
  - **M.Sc. in Computer Science** — University of Salzburg (Focus: Backend Development, Database Systems, Distributed Systems, Software Engineering)
  - **B.Sc. in Software Engineering** — Arba Minch University (CGPA: 3.86 / 4.0)
